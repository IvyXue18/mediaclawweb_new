- `test:p1`: 支付、发码、Zpay、福利、分销、渠道商扩展回归。

- `test:phase1`: 激活码、积分、支付、试用升级、插件消费接口的阶段门禁。
- `test:phase2`: 分销、福利、渠道商/贴牌的阶段门禁。
- `test:phase3`: 后台和用户中心受保护页面 smoke，验证权限跳转和无 5xx/应用错误。
- `test:phase4`: 公开官网页面 smoke，验证核心公开路径标题和无 5xx/应用错误。
- `verify:web`: P0 + P1 + TanStack build。

`@/extensions/*` 和 `@/themes/*`。当前仓库通过

## 迁移测试原则

1. 每个迁移阶段必须同时迁测试；阶段结束不是代码搬完，而是对应门禁通过。
2. 旧测试的业务预期不能改。迁到 TanStack 时只允许调整 import、route handler 入口、mock 边界和请求构造。
3. 业务规则优先落到 `src/modules/*/service.ts`，API route 只做鉴权、参数解析、调用 service 和响应封装。
4. 支付、发码、积分、分销、福利和插件消费接口都必须覆盖幂等。
5. 插件调用的接口优先写 contract test，固定请求、响应和副作用。
6. 页面迁移不能替代业务测试；页面 smoke 只证明用户路径没有明显断裂。
