这里是 MediaClaw 唯一的问题处理入口。先按问题现象查找对应答案，再依次执行检查步骤。

<Callout type="warning">
  遇到问题时先保留当前页面和数据池，不要立即清空缓存、卸载插件或全量重试，以免丢失任务进度、重复写入数据或重复消耗积分。

## 先完成这 5 项基础检查

1. 确认使用的是当前发布版本的 MediaClaw；涉及飞书时，模板也要使用当前版本。
2. 刷新目标平台页面，等待内容加载完成，再重新打开插件。
3. 确认当前是作品详情、账号主页或关键词搜索结果页等受支持页面。
4. 分别检查抖音/小红书登录、MediaClaw 登录和激活码验证状态。
5. 如果页面出现验证码、登录提示或访问限制，先人工处理再继续。

## 安装、登录与页面识别

### 安装后找不到插件

在 Chrome 扩展管理页确认 MediaClaw 已启用，并把它固定到工具栏。离线安装时还要确认开发者模式已打开、加载的是正确扩展目录。

### 插件提示当前页面不支持或页面匹配不对

搜索页、账号主页和作品详情页对应不同功能。先确认停留在正确页面，再按顺序操作：

1. 等待页面内容加载完成。
2. 刷新当前页面。
3. 关闭插件面板后重新打开。
4. 搜索页先输入关键词并完成一次平台搜索。
5. 关闭其他同时运行的采集窗口，避免页面状态互相影响。

页面能正常浏览但持续无法识别时，复制诊断信息并记录当前页面类型。

### 刚刚还能采集，突然持续提示刷新或采集失败怎么办

如果同一账号、同一页面刚刚还能正常采集，随后反复出现“请刷新当前网页后重试”“插件未能连接当前网页的采集脚本”或类似提示，并且刷新页面、关闭插件面板、重启浏览器后仍未恢复，不要立即判断为账号风控或插件配置错误。浏览器版本更新不完整、扩展运行环境异常或页面脚本没有正常注入，也会造成这种现象。

按下面顺序排查：

1. 新开一个抖音或小红书页面，再重新打开插件测试。
2. 在浏览器扩展管理页重新加载 MediaClaw，并确认已允许插件访问当前网站。
3. 将 Chrome、Edge 或其他 Chromium 浏览器更新到当前稳定版本，完全退出浏览器后重新打开。
4. 更新后仍持续失败时，先导出重要数据，再修复或覆盖安装浏览器；不要先卸载插件、清空插件缓存或删除浏览器用户资料。
5. 恢复后先采集一条普通作品，再测试搜索页或批量任务。

出现以下情况时，更可能是浏览器运行环境问题：

- 页面内容可以正常浏览，但插件始终无法连接或开始采集。
- 账号、页面和插件设置都没有变化，只有更新、修复或重新安装浏览器后恢复。
- 同一账号在另一套正常的 Chromium 浏览器环境中可以使用。

如果只有某一个平台账号失败，或者页面出现验证码、登录提示、访问限制，再按账号登录或平台风控方向处理。

<Callout type="warning">
  浏览器修复或重新安装是否保留插件设置，取决于浏览器用户资料是否被保留。操作前先导出重要数据，不要删除浏览器用户资料目录。
</Callout>

### MediaClaw 已登录，为什么功能仍不可用

MediaClaw 账号、激活码权限和目标平台登录是三件事。分别确认授权已验证、积分或权益足够，以及抖音/小红书网页仍处于登录状态。

## 采集、字段与下载

### 采集数量少于设置值或任务提前结束

设置值是上限，不是保证数量。依次检查：

1. 平台实际结果是否不足。
2. 发布时间、最低互动、主题或低粉筛选是否过严。
3. 页面是否停止加载新内容。
4. 是否出现验证码、限流或详情打开失败。
5. 设置中的无新增超时、最大采集时长是否被调得过低。

先减少目标数量并使用默认等待策略测试，不要通过同时开多个窗口弥补数量不足。

### 为什么正文、标签、收藏、评论数或媒体链接为空

列表页只能提供摘要字段。开启 **采集增强**，再选择“仅补采未补采详情”，插件才会逐条进入详情补正文、标签、互动数据和媒体链接。

<ImagePlaceholder caption="采集增强与补采范围设置截图" />

### 为什么缺少博主粉丝数、赞藏数或账号属性

开启作者指标补采。该过程会额外打开博主主页，因此采集耗时和页面访问量都会增加。不需要这些字段时，可以不补采，并在飞书表格中隐藏对应字段。

### 评论为什么不完整或客资表为空

插件只处理页面实际加载的一、二级评论，不会无限展开所有楼层。检查评论加载上限；需要客资时，还要开启评论客资筛选并配置关键词或 IP 规则。没有评论命中筛选规则时，客资表为空是正常结果。

### 图片或视频下载失败

先确认原作品仍可正常访问，再检查浏览器下载权限和本地空间。批量图片下载时缩小数据范围，排除已经失效的远程图片后重试。

## 筛选、导出与本地数据

### 导出什么范围

CSV、Markdown 和图片导出以当前数据池视图为基础。导出前先确认筛选条件和记录数量。

### CSV 中文乱码怎么办

使用支持 UTF-8 的 Excel、Numbers 或其他表格工具打开；长正文和逐字稿也可以改用 Markdown。

### 清空缓存后还能恢复吗

插件不会保证恢复已清空的本地记录。重要数据应先导出或同步到飞书，再执行“清理已同步数据”或“清空当前页面缓存”。

## 关键词研究与积分

### 现在哪些研究能力可用

当前已开放 **选题方向、找对标账号、分析长尾需求、关键词舆情扫描**。其中长尾扩词可以先免费获取联想词，继续生成分析需要积分；其他分析会在开始前显示预计消耗。

### 为什么有效样本不足

当前搜索词过窄、平台筛选过严、页面未加载完成或详情不可访问，都可能导致样本不足。换更明确但有结果的词，或放宽筛选后再试。

### AI 分析失败会不会丢掉采集结果

选题方向、找对标账号、长尾和舆情流程会尽量保留已经获得的样本或扩展词。界面提供已有进度时，优先基于现有数据重试，避免重复采集。

### 账号研究、爆款拆解、选题库和内容创作在哪里

从插件侧边栏打开 **AI 工作台**。其中 **内容研究** 保存账号研究和单篇拆解，**选题库** 保存你主动收藏的选题，**内容创作** 保存从研究或选题发起的图文稿与视频稿。具体入口见[熟悉核心界面](/docs/getting-started/core-interface)。

### Agent 已安装，为什么仍然不能调用插件

Agent 接入包和浏览器扩展是两个安装对象。先确认当前 Chromium 浏览器中已启用社媒虾扩展，再到 **设置 → Agent 接管** 开启本机调用；首次连接还需要在同一页面核对设备并点击 **批准配对**。完整排查见[接入 Agent，结合知识库创作](/docs/create/agent-workflow)。

## 图片与视频转文字

### 图片转文字是否扣积分

当前配图文案提取是会员权益，不按图片张数额外扣积分。能否使用以激活码权益为准。

### 视频转文字如何计费

按单条视频时长计算，当前标准为 2 积分/分钟，不足 1 分钟按 1 分钟。提交前会显示预计消耗，确认后才开始。

### 为什么没有逐字稿入口

记录必须包含可访问的视频或音频链接和时长。只有列表摘要时，先执行采集增强补齐详情。

### 视频逐字稿或图片文案提取失败

- 图片文案：确认记录是图文作品、图片链接仍可访问，并已采集到配图。
- 视频逐字稿：确认记录包含视频或音频链接和时长，再检查预计积分、余额和任务错误。
- 单条任务失败后先针对该记录重试，不要直接全量重跑。

### 本地和云端转写怎么选

没有本地转录环境时使用云端模式最省事，每次会先展示预计积分；已经拥有本地转录权益并完成环境配置时，可以选择本地模式；自动模式会先检查本地条件，需要转云端时再请求确认。具体说明见[插件配置](/docs/settings/plugin#视频逐字稿处理方式)。

### 逐字稿或图片文案不准确

背景音乐、多人说话、口音、花字、竖排字、低清图片和复杂排版都会影响结果。专有名词、数字和关键信息必须人工校对。

## 账号监控

### 加入监控后为什么没有立即出现作品

监控按规则扫描前一天发布的作品，并在观察期内判断点赞阈值。可以使用 **立即执行扫描** 测试，但没有命中不等于失败。

### 监控为什么被跳过或失败

先在监控列表检查任务状态：

- **成功无命中**：已扫描，但作品没有达到规则阈值。
- **跳过**：检查积分、授权和执行条件。
- **失败**：检查账号主页能否访问和错误详情。
- **尚未执行**：等待设定整点，或使用立即执行扫描测试。

### 为什么飞书没有监控通知

先确认扫描成功且有作品达到阈值，再检查监控表名和机器人 Webhook。普通“无命中”任务不会产生潜在爆款通知。

## 飞书同步

<Callout type="important">
  首次使用飞书同步前，必须先完成[飞书模板配置](/docs/settings/feishu-template)，包括复制模板、设置权限、填写
  base 链接和核对数据表名称。
</Callout>

### 点击同步提示没有未同步数据

默认同步范围只处理当前页面缓存中尚未成功同步的记录，这是为了避免重复写入。需要重新处理时，到插件设置 → 采集与筛选 → 采集策略，把同步范围临时改为“全部数据”，完成后建议改回推荐值。

<ImagePlaceholder caption="同步范围从未同步数据切换到全部数据的截图" />

### 同步飞书但表格没有数据

按下面顺序检查：

1. **插件和模板版本**：确认两者都是当前发布版本，避免新插件继续使用结构不兼容的旧模板。
2. **目标文档一致**：复制多个模板时，确认插件配置的文档就是当前正在查看的文档。
3. **文档权限正确**：必须是“互联网获得链接的人可编辑”；“可阅读”或“组织内可编辑”都无法满足当前写入方式。
4. **链接是 base**：URL 路径中必须是 **/base/**，不能是 **/wiki/**。wiki 链接说明模板仍在知识库或文档库，应先移动到云盘。
5. **数据表名称一致**：逐一核对单笔记、关键词笔记、博主信息、博主笔记、客资和监控表。飞书侧改名后，插件侧也要同步修改。
6. **模板字段未被破坏**：不要删除或修改模板已有字段名称和字段类型；可以新增辅助字段和视图。
7. **平台视图正确**：模板默认可能停留在小红书视图。同步抖音数据后没有找到记录时，切换到抖音对应的数据表或视图。
8. **同步范围正确**：默认只处理未同步记录。重试前先检查飞书是否已经写入，避免重复处理。
9. **查看执行明细**：找到失败或部分成功的记录，查看错误详情并复制调试链接；没有调试链接时，保存完整报错截图。

### 同步成功但字段缺失

同步只会写入已经采集到的数据，不会自动创造缺失字段：

- 缺作品详情 → 先执行采集增强。
- 缺作者数据 → 开启作者指标补采。
- 缺评论 → 开启附加评论并设置加载上限。
- 缺图片文案或逐字稿 → 先对记录执行对应提取。
- 客资表为空 → 检查筛选规则是否有命中，以及客资表名是否配置正确。

补齐后只重新同步对应记录，不要默认全量重跑。

### 同步超时后要不要立即重试

先到飞书检查记录是否已经写入，再查看执行明细。外部写入可能已经成功但响应较慢，直接全量重试可能产生重复处理。

### 能否修改飞书模板

可以新增自己的视图和辅助字段，但不要改动模板已有字段名称、字段类型和必需表结构。数据表改名后，插件配置也必须同步修改。

## 飞书模板字段

### 飞书模板里的视频脚本提取不出来

这里指飞书模板中使用外部字段能力进行的视频转文字，不是插件内置的逐字稿提取。外部字段同时使用人数较多时可能触发并发限制：

1. 点击具体单元格右侧的重试按钮。
2. 先用少量记录测试，不要一次重试整列。
3. 刷新表格或换一个时段再次执行。
4. 持续失败时检查该字段使用的外部服务密钥、额度和字段配置。

## 使用风险

### 可以同时开多个窗口批量采集吗

不建议。同一账号多窗口同时高速操作更容易触发验证码、限流或其他平台风控。不同账号在同一设备同时运行也仍有被关联判断的风险。优先单窗口、分批执行，并保留默认等待节奏。

### 采集到的内容可以直接商用吗

不可以据此推定。公开可访问不等于获得转载、改编或商用授权；请遵守平台规则、著作权、个人信息和素材授权要求。

## 仍然无法解决

1. 保留发生问题的页面和数据池。
2. 记录操作时间、平台、页面类型和预期结果。
3. 打开插件右上角 **执行明细**。
4. 点击 **复制诊断信息**；同步问题还应复制对应记录的调试链接。
5. 连同错误截图、必要的样本 URL 和完整报错一起提交给支持人员。

<Callout type="danger">
  提交前检查内容，不要发送激活码、飞书 Webhook、API
  Key、账号密码、验证码或其他敏感凭证。
</Callout>
