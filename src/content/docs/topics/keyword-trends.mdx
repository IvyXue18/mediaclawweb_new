当你只有一个大方向时，不要立即把大词当成标题。先用一个种子关键词观察搜索样本，再把它拆成具体人群、场景、问题和表达方式。

## 选择种子词

种子词可以来自：

- 行业或赛道：如露营、轻食、职场沟通。
- 产品或品类：如咖啡机、扫地机器人、护眼灯。
- 目标人群：如新手妈妈、租房党、自由职业者。

优先选择用户真的会在平台搜索的表达。词太大时样本混杂，词太小时又可能没有足够结果。

1. 在小红书或抖音 PC 端搜索种子词（如”近视手术”），打开 MediaClaw 侧边栏并点击**关键词洞察**。
2. 在**内容策略**分类下切换到**选题方向**标签——它能回答三个问题：这个赛道的选题热度怎么分布、哪些内容角度更容易拿到自然流、现在开始发内容该优先切哪个方向。
3. 社媒虾会自动先把平台自带的筛选面板设为**发布时间：半年内**，让采样聚焦近半年还在起效的内容，再**开始选题方向**。
4. 查看结果：整体热度与赞数分布、内容分布全景（各内容角度的样本量占比、自然流可行性、用户意图）、核心爆款细分词、优先选题（附形式建议与执行提示）。

## 把方向改写成候选选题

一个合格候选选题至少包含三项：

- **为谁写**：明确人群或使用阶段。
- **解决什么**：一个具体问题、顾虑或目标。
- **用什么证据**：样本、案例、实测、对比或经验。

例如，把“咖啡机选购”改成“第一次买半自动咖啡机，预算 3000 元最容易忽略的 4 个成本”。
