# 1. 数据问题

## 1.1 点击同步，显示没有未同步数据

这是防止同步重复数据到飞书而做的限制，你可以在右上角【系统配置】——【采集与获客】——【采集策略】——【同步范围】选择 **同步当前页面缓存区全部数据**，这样就能全部同步到飞书，不再局限于未同步状态的数据。

这个最好是应急的时候改一下，平时还是用仅同步未同步的数据，不然容易在飞书堆积很多重复数据。

### 1.2.3 字段名称/类型被修改

模板表格中，**模板自带的所有字段名称和类型不可修改**，改了之后，数据就写不进去。

不过，可以加新的字段，不影响数据写入。

### 1.2.4 数据表名被修改

飞书表格的数据表名，必须和插件配置这边的表名一致。如果你修改了飞书多维表格数据表的名字，一定要同步修改插件配置中的对应表名。

# 4. 账号风险

## 4.1 能开多窗口同时操作吗？

技术上可以，但**不建议**，原因如下：

<strong>平台可能认为你行为异常：</strong>
正常人只有一双手，不会同时在多个窗口高速操作。平台的风控系统会注意到这种“不像人”的行为，可能触发验证码、限流，严重时封号。

- **同一账号多窗口操作风险最高**
  如果多个窗口操作的是**同一个账号**，被识别为异常的概率大幅上升。
- **不同账号多窗口相对好一点**
  但同一台设备、同一时间跑多个账号，平台仍可能关联判断。

**总之，本产品会模拟的是一个人在操作，开多窗口就变成了几个人同时用一台电脑，平台会起疑心。**
