MediaClaw 的核心界面分为两部分。

- 侧边栏负责发起采集和分析任务，暂存原始数据；
- AI工作台负责深度内容研究、选题与创作。

## Part1：侧边栏

### 1.主页和平台选择

若浏览器当前打开的页面不是支持的社交平台页面，默认会调到插件主页。可以点击跳转到对应平台。
