这是一个方法页：把关键词趋势、下拉词长尾、账号研究和爆款延伸这几种选题来源编排在一起，批量产出一批可执行选题。具体的每一步操作分别在对应正文页中说明，这里只讲怎么组合、怎么判断优先级。

## 四种选题来源

| 来源       | 适合场景                         | 操作页                                                             |
| ---------- | -------------------------------- | ------------------------------------------------------------------ |
| 关键词趋势 | 判断一个方向是否值得投入         | [用关键词判断趋势](/docs/topics/keyword-trends)                    |
| 下拉词长尾 | 找具体、精准的长尾需求           | [用下拉词扩展长尾选题](/docs/topics/autocomplete-long-tail)        |
| 账号研究   | 复用一个账号已验证的表达规律     | [账号研究：选题、结构与表达规律](/docs/benchmark/account-research) |
| 爆款延伸   | 从一篇爆款衍生出近 / 中 / 远选题 | [单篇爆款拆解](/docs/viral-research/single-post-breakdown)         |

## 如何判断优先级

不同来源产出的选题，可信度和验证方式不同：关键词趋势和下拉词长尾反映的是"需求是否存在"，账号研究和爆款延伸反映的是"打法是否已被验证过"。优先选择两者都成立的选题——既有需求信号，又有可参考的表达方式。
