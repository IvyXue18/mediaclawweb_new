## 支持哪些 Agent

| 宿主Agent | 状态 | 安装时你要做什么                                                              |
| --------- | ---- | ----------------------------------------------------------------------------- |
| Codex     | 可用 | 不用动手。把安装提示词发给它，它自己一路装到底                                |
| WorkBuddy | 可用 | 不用动手。把安装提示词发给它，它自己一路装到底                                |
| 豆包工作  | 可用 | 先让豆包准备安装文件和配置清单，再手动新建本地 STDIO 连接器，详见下方独立教程 |

**Codex、WorkBuddy** 按下面三步操作。**豆包工作** 先完成第一步、复制豆包工作专用的安装提示词，再跳到[豆包工作：单独配置连接器](#豆包工作单独配置连接器)。

## 第一步：复制安装提示词

1. 打开社媒虾扩展 → **右上角系统配置 → Agent 接管**。
2. 打开 **允许本机 Agent 调用社媒虾**。
3. 展开下方的 **连接 Agent**，找到你要用的宿主，点 **复制安装提示词**。

## 第二步：发给 Agent 自己装

在 Codex 或 WorkBuddy 里新建一个对话，把刚才复制的内容原样发送。接下来这些都由 Agent 完成：

- 识别当前宿主，注册官方 marketplace 并安装接入包。
- 识别你的系统和芯片（Windows／macOS／Linux，x64／ARM64），获取并校验对应的官方运行时。
- 装完后如果当前对话加载不到新工具，它会自己开一个续接对话，把任务带过去。

## 第三步：回插件批准配对

Agent 检测到扩展后，插件的 Agent 接管页会出现待批准的设备。

1. 核对设备名称和 **设备指纹**。
2. 点 **批准配对**。
3. 回到 Agent 对话，它会自动复查连接，不需要你回复"已批准"。

## 豆包工作：单独配置连接器

**为什么豆包工作需要多配一步？** Codex、WorkBuddy 可以由 Agent 完成接入包安装和工具注册；豆包工作目前需要你在界面里手动保存一个自定义连接器。安装提示词会让豆包准备好运行文件、整理出配置清单，而连接器负责告诉豆包：**从哪里启动本机的 MediaClaw 工具、用什么配置连接它**。因此，拿到安装清单后，还需要完成下面的连接器配置，豆包才能调用社媒虾。

这个连接器使用 **本地电脑 / STDIO** 方式运行。请在安装了社媒虾扩展的同一台电脑上操作，并保持浏览器和扩展打开。配置完成后，还要回扩展批准豆包工作的设备配对。

保留这份清单，接下来逐项复制到连接器设置。然后点击左侧 **技能 · 连接器 · 伙伴**。

## 升级

Agent 的能力也随着插件版本迭代，发布新版本之后，你需要：

1. 在已有的 MediaClaw 对话里直接说 **升级 MediaClaw Agent**。这句话本身就是授权。
2. 它会刷新官方来源、安装、核验版本，进行安装覆盖。
3. **完全退出Agent并重启应用**。
4. 回到原来的对话说一句 **继续**。
5. 它会重新检查状态；只有确认新版本**已激活**，才会宣布升级完成，并自动接着做你之前没做完的事。
