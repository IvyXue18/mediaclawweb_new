插件内创作适合“研究已经完成、选题已经明确、现在需要一版可继续修改的稿件”。入口集中在 AI 工作台，不需要导出文件，也不需要先安装 Agent。

## 可以从哪里发起

- **账号研究**：从账号的选题系统和可复用风格中选择一个方向。
- **单篇拆解**：从“把原题讲深、换个场景写、换个方向写”等扩展选题发起。
- **选题库**：从已经收藏、准备执行的选题卡发起。

这些入口会把选题来源和研究上下文带进创作任务。不要只复制一个标题后另开空白任务，否则会丢失证据和来源关系。

## 操作步骤

1. 打开插件的 **AI 工作台**，进入账号研究、单篇拆解或选题库。
2. 在准备执行的选题上点击 **直接创作**。
3. 选择主标题，并确认核心判断。
4. 选择 **图文笔记** 或 **视频笔记**。
5. 修改内容大纲。每行代表一个内容步骤，可以直接补入自己的案例、经历和数字。
6. 按需启用创作档案，填写产品/服务、目标人群、核心价值、转化目标、必须提及和必须避免的内容。
7. 按需选择一个已经保存的账号风格；如果不选，系统只使用本次研究与创作简报。
8. 提交生成，在 **内容创作** 列表查看结果并继续人工修改。

## 图文和视频分别会生成什么

| 类型     | 主要输出                           | 适合继续检查的重点                                 |
| -------- | ---------------------------------- | -------------------------------------------------- |
| 图文笔记 | 标题、正文、逐页配图建议           | 页数与信息节奏、图片和文字如何分工、配图是否可执行 |
| 视频笔记 | 标题、发布正文、可直接口播的逐字稿 | 开头钩子、口语节奏、停顿与转折、画面和口播是否一致 |

如果选题来自一篇图文拆解，生成会尽量继承原内容有效的页数、逐页职责和图文分工，但会替换为新选题内容。你仍需检查是否与原作过度相似。

## 创作档案与账号风格不是一回事

- **创作档案回答“为谁、写什么业务、希望产生什么行动”**：产品、目标人群、核心价值、转化目标和合规边界。
- **账号风格回答“怎么写”**：定位、常见结构、表达节奏、视觉规律和可复用的创作规则。

两者可以叠加。不要用账号风格替代业务事实，也不要把对标账号的案例、数据或第一人称经历写成自己的。

## 什么时候改用 Agent

遇到以下情况时，改走 [Agent 创作](/docs/create/agent-workflow) 更合适：

- 需要先补采一批数据，再比较后决定选题。
- 需要同时读取多个账号研究、单篇拆解或历史稿件。
- 需要结合本地品牌手册、产品资料、访谈记录或个人知识库。
- 需要产出系列选题、内容日历、跨平台版本或附带证据的长文。
- 需要在创作过程中继续追问、核验或改变研究范围。

## 下一步

初稿确认后，不要只保留一段最终正文。把研究来源、创作简报、使用的风格、稿件版本和发布结果一起写入[内容资产](/docs/reuse/content-assets)。
