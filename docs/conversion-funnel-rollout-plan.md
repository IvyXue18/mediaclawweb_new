# MediaClaw 转化链路分批方案

## 目标排序

本轮不再用“注册数”作为唯一北极星。官网和插件共同服务四个目标，优先级是：

1. 下载插件：让新用户先拿到可用工具。
2. 激活插件：让用户知道在哪里输入激活码，或在需要权益时被自然引导。
3. 领取试用并了解渠道来源：只在用户有明确使用意图时收集来源信息。
4. 付费续费：价格页保留购买主路径，试用作为犹豫用户的辅助路径。

## 允许并存的三条路径

### 下载优先用户

路径：官网 -> 下载插件 -> 免费功能先用 -> 点到高级功能 -> 插件引导领取试用或购买。

这类用户不注册是正常的。本轮重点不是强迫注册，而是补齐下载、安装、触发高级功能门槛、从插件回到试用/付费页的可观测性。

### 试用优先用户

路径：官网看到领取试用 -> 注册/登录 -> 填渠道来源 -> 获得试用码 -> 下载/打开插件 -> 输入激活码 -> 马上完成一个高级功能。

当前最大问题是领取后容易停住。本轮先保证登录回跳和领取事件可观测；下版再把“领取后马上使用”的页面和插件入口做顺。

### 付费优先用户

路径：价格页 -> 登录后仍回到价格页/支付流 -> 支付 -> 进入激活码/订单页。

价格页不把强购买意图分流到试用。试用入口只作为辅助选项出现在下载上手路径和插件门槛处。

## 本次上线：第一批

第一批只修断点和回跳，不改大面积文案/页面结构：

- 补 `/auth-callback` 兜底路由，避免历史 `redirect` 流程和支付成功页落到 404。
- 价格页未登录点击购买后，登录完成回到原价格页/原查询参数，不再默认进设置页或福利页。
- 福利中心未登录点击领取后，登录完成回到当前 `/welfare?...`，保留 `source`、`entry` 等参数。
- 支付 checkout 的成功回跳改成同源目标，不再把站内支付成功 URL 包到缺失的 `/auth-callback`。
- 领取试用完成后仍展示激活码入口，避免用户拿到码后找不到下一步。

验收口径：

- `/pricing?source=extension&entry=feature_gate` 未登录点击购买 -> 登录 -> 回到 pricing 继续购买。
- `/welfare?source=extension&entry=feature_gate&feature=keyword_opportunity` 未登录点击领取 -> 登录 -> 回到 welfare 并保留参数。
- 支付成功回调最终落到 `/settings/payments?...`，不出现 `/auth-callback` 404。

## 本次上线：第二批

第二批补可观测性，回答“用户到底卡在哪里”：

- 网站首方埋点：`page_view`、`pricing_view`、`download_click`、`chrome_store_click`。
- 注册/下单/支付链路：`sign_up_success`、`checkout_created`、`payment_success`。
- 福利领取链路：`trial_claim_started`、`trial_claim_success`，带上 `source`、`entry`、`install_id`、`feature`、`rewardType`。
- 插件门槛链路：`feature_gate_shown`、`trial_cta_clicked`、`pricing_cta_clicked`。
- 插件跳转官网时补齐 URL 参数：`source=extension`、`entry=feature_gate`、`feature`、`intent`、`reason`、`install_id`。
- 后台业务分析页新增门槛/CTA/领取数据，先用于观察，不用于做复杂归因。

验收口径：

- 后台能看到 UV/PV、看价格、下载点击、下单、支付、插件门槛、试用 CTA、购买 CTA、试用领取。
- 插件跳转到福利/价格页的 URL 可以看出入口、功能和意图。

## 下个版本：第三批

第三批再改体验，不和本轮断点修复混在一起判断：

- 官网首页 CTA：主 CTA 保持下载，试用作为“需要高级功能时可领取”的辅助承诺。
- 下载页第 2 步：并列放“领取试用”和“购买激活码”，并说明已有激活码回插件配置。
- 福利领取成功页：展示激活码、复制按钮、安装入口、已安装配置入口、下一步高级任务。
- 插件授权状态卡：在侧边栏常驻展示当前权益状态、输入激活码入口、领取试用/购买入口。
- 插件高级功能门槛弹窗：明确三个动作：领取 2 天试用、直接购买、已有激活码去输入。
- 领取后引导用户立刻完成一个高价值任务，而不是只停在“已领取”。

建议本轮上线后观察 3-7 天，再动第三批。第一、二批解决的是“路断了”和“看不见”；第三批解决的是“更顺”和“更能转化”。
