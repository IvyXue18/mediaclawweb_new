内容创作不是从一个标题凭空生成全文，而是把平台证据、目标人群、自己的知识与创作边界组合起来。社媒虾 MediaClaw 提供两种创作入口：在插件内快速生成初稿，或接入 Agent 完成更开放的研究与创作任务。

<Callout type="important">
  两种方式不是两套彼此割裂的产品。插件负责采集和保存专有数据，AI
  工作台负责结构化研究与快速生成；Agent
  可以读取这些资产，再结合你授权的本地文件和知识库完成更复杂的工作。
</Callout>

## 先看完整流程

**采集原始内容 → 补齐正文、评论、图片文案或逐字稿 → 形成账号/单篇研究 → 筛选选题 → 选择创作入口 → 人工校对发布 → 写回复盘结果**

创作是资产循环中的一环，不是流程终点。研究材料、选题、账号风格、创作简报、稿件和发布结果都应保留来源关系，下一轮才能继续复用。

## 两种创作方式怎么选

| 你的情况                                       | 插件内 AI 工作台   | Agent 创作                                                        |
| ---------------------------------------------- | ------------------ | ----------------------------------------------------------------- |
| 想从账号研究、单篇拆解或选题卡快速生成一版稿件 | 最合适             | 可以                                                              |
| 需要固定的图文稿或视频口播稿结构               | 最合适             | 可以                                                              |
| 需要同时参考多个账号、多篇内容或多轮研究       | 可分次处理         | 更合适                                                            |
| 需要结合本地品牌资料、产品文档、采访、历史稿件 | 需手动粘贴关键信息 | 更合适                                                            |
| 需要先补采、比较、追问，再决定写什么           | 需在不同功能间操作 | 更合适                                                            |
| 需要团队在飞书里继续协作                       | 生成后同步或复制   | 可把飞书作为协作资产来源，但取决于 Agent 客户端已获授权的连接能力 |

### 路径 A：插件内 AI 工作台

适合目标明确、希望快速得到可编辑初稿的任务。你可以从账号研究、单篇拆解或选题库点击 **直接创作**，选择图文或视频，确认标题、核心判断、大纲、创作档案和账号风格后生成。

继续阅读：[在插件内生成图文或视频稿](/docs/create/plugin-workbench)。

### 路径 B：Agent + 你的知识库

适合研究范围更大、材料分散、需要多步推理或需要使用自有知识的任务。Agent 可以按目标调用 MediaClaw 采集和读取已有资产，先形成证据结论，再把本地知识库中的品牌事实、案例和表达规范加入创作。

继续阅读：[接入 Agent，结合知识库创作](/docs/create/agent-workflow)。

## 无论选择哪条路，都先准备这 6 类信息

1. **目标人群与场景**：这篇内容具体写给谁、在什么情境下阅读。
2. **要解决的问题**：一篇内容只承载一个主要判断或行动目标。
3. **平台证据**：原始链接、正文、互动、评论、逐字稿和研究结论。
4. **自有事实**：产品信息、真实案例、实测数据、采访与个人经历。
5. **表达要求**：目标平台、图文或视频、长度、语气和账号风格。
6. **边界条件**：必须提及、不能声称、需要核验和没有授权的内容。

## 发布前检查

- 是否真正回答了目标用户的问题，而不是只复述热门内容。
- 事实、参数、案例和引用是否可验证。
- 是否区分平台样本中的客观事实、分析判断和创作建议。
- 是否与参考作品在标题、结构和句子上过度相似。
- 图片、视频、音乐和引用是否拥有使用权限。
- 是否保留自己的观点、证据和表达，并符合平台与广告规则。

<Callout type="danger">
  采集到公开内容不等于获得转载或商用授权。Agent
  能读取材料，也不代表它可以替你判断全部版权与合规风险；发布前仍需人工确认。
</Callout>

## 下一步

完成初稿后，把稿件、来源和发布结果纳入[内容资产沉淀与复用](/docs/reuse/content-assets)，让下一次研究和创作不再从零开始。
