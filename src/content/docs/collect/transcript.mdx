## 方法一：在插件里提取

提取结果会回填到原记录，一次给两份：

- **完整逐字稿**：适合通读、检索、归档和交给 AI 继续处理。
- **分句节奏稿**：保留每句话的起止时间，适合观察开头钩子、铺垫、转折和结尾引导分别用了多久。

### 提取单条视频逐字稿

1. 打开一篇小红书视频笔记或抖音视频，先将作品采集到数据池。
2. 在数据池中找到这条视频记录，点击**提取视频逐字稿**。
3. 确认弹窗中的视频时长和预计积分消耗，再开始提取。
4. 提取期间可以继续浏览其他内容；记录上的按钮会显示**视频逐字稿提取中**。
5. 完成后会自动打开结果弹窗。以后也可以点击记录上的**查看视频逐字稿**重新打开。

### 批量提取多条视频逐字稿

当前页面至少有 2 条可提取的视频时，数据池工具栏会出现**逐字稿 N**入口。批量任务适合一次处理一批已经采集完整的对标视频。

1. 点击**逐字稿 N**，打开批量提取弹窗。
2. 勾选要处理的视频。列表会逐条显示视频时长和预计积分，一次可选择 2～20 条。
3. 核对总预计积分和当前余额，点击**确认提取**。
4. 任务会在后台继续执行；关闭侧栏不会中断。再次打开侧栏可以查看已完成、失败和等待中的数量。
5. 成功结果会自动写回对应记录；失败的记录可以回到数据池单独重试。

批量列表只显示**已采集详情、能计算时长、尚未提取且当前不在处理中的视频**。某条视频没有出现在列表时，先确认它是否已采集完整，以及记录中是否有视频时长和原始媒体链接。

### 查看、复制和继续使用

在结果弹窗中，可以分别复制**完整逐字稿**和**分句节奏稿**。也可以导出 CSV、Markdown 或同步飞书，不需要再手动粘贴回去。

逐字稿来自语音识别，遇到人名、品牌名、方言、背景音乐或多人重叠说话时，仍建议结合原视频人工校对。

## 方法二：用飞书模板的「视频文案提取」字段

这条路适合一次要处理一大批视频、并且能不嫌麻烦，自己配置key的用户。语音识别不在插件里跑，而是由飞书多维表格的第三方字段捷径对接阿里云百炼完成：把视频的原始文件链接同步进表格后，字段会对整列逐条转写。

### 操作步骤

1. 按[飞书模板：功能与配置](/docs/settings/feishu-template)复制模板、移动到云盘、设置权限，并在插件里填好 base 链接，能够成功完成数据同步。
2. 在模板的[视频转文字](/docs/settings/feishu-template#视频转文字)字段里，填入自己在阿里云百炼申请的key。
3. 按[同步到飞书多维表格](/docs/collect/feishu-sync)把数据池记录写进模板。视频的**原始文件链接**会跟着一起写入，字段读的就是这一列。
4. 视频转文案自动提取。

### 转不出来时怎么办

这个字段捷径使用人数较多、有并发限制，多条同时提取时容易出错。遇到报错，点单元格右侧的重试按钮，或者换个时段再跑，一般刷新一下就能出来。
