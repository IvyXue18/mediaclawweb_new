## 文字版配置教程

### 1. 复制 MediaClaw 模板

打开 [MediaClaw 飞书模板](https://my.feishu.cn/base/H9fAb5QYtagaLDsjgdPcaliGnyf?from=from_copylink)（也可以在插件的 **飞书归档目标配置 → 获取模版** 打开），点击右上角的 **使用该模板**，复制到你自己的飞书中。

复制好模板后，模板默认会被复制到「我的文档库」。请移动到 **云盘**。需要从文档库移动到 **云盘 → 我的文件夹**。

<DocImage

<DocImage

### 3. 设置权限为「互联网获得链接的人可编辑」

模板权限必须设置成 **互联网获得链接的人可编辑**。

<DocImage
  src="/imgs/docs/settings/feishu-template/07-设置互联网可编辑权限.webp"
  caption="在「分享」里把链接权限设为「互联网获得链接的人 · 可编辑」"

  width={1600}
  height={505}
/>

| 设置                          | 结果                              |
| ----------------------------- | --------------------------------- |
| 互联网获得链接的人 **可编辑** | ✅ 正确                           |
| 互联网获得链接的人 **可阅读** | ❌ 无法写入数据                   |
| **组织内**获得链接的人可编辑  | ❌ 插件以链接访问，非组织成员身份 |

### 4. 复制链接，填到插件里

复制模板链接，填到插件的 **偏好设置 → 飞书多维表格文档 URL**。

### 5. 检查表名

插件的 **飞书归档目标配置** 里有六类数据表名称，必须与飞书模板左侧的实际数据表名称一一对应：

- 单笔记采集
- 关键词笔记采集
- 博主信息表
- 博主笔记采集
- 评论区客资采集
- 监控内容表

<DocImage
  src="/imgs/docs/settings/feishu-template/10-检查表名一致.webp"
  caption="插件里的六个表名要和飞书模板左侧的表名一一对应（顺序可以不同）"
  captionEn="The six table names in the extension must match the tables in the Feishu template one-to-one (order can differ)"
  width={1522}
  height={1206}
/>

这几张数据表的名称和飞书模板的表名 **必须保持一致**（排列顺序可以不同），后续版本升级可能还会新增数据表。如果名称不一致，或你要改动某张表的名称，需要两边一起改、对应上，否则数据无法同步。

<Callout type="danger">
  表格里新增自己的字段不影响同步，但不要修改模板自带字段的名称和类型，改了以后数据可能写不进去。
</Callout>

### 6. 测试同步一条数据

<DocImage
  src="/imgs/docs/settings/feishu-template/11-测试同步一条数据.webp"

4. 打开飞书模板，确认表格里出现新数据。

## 配置飞书通知（选用）

如果需要接收账号监控日报、批量分析完成或余额不足等消息，需要单独配置一个飞书群机器人的 Webhook，填入插件 **监控任务 → 监控通知** 里的 **通知 Webhook**。该字段与上面的数据表连接分开保存，修改后会显示自动保存状态；不填写不影响普通表格同步。

### 1. 建群并进入群机器人设置

拉一个飞书群（只拉自己也可以），点击群右上角的更多菜单进入 **设置**，在设置里找到 **群机器人**。

进入插件 **监控任务 → 监控通知 → 飞书机器人通知**，把复制的 Webhook 粘贴到 **通知 Webhook** 字段。该字段独立自动保存，等待状态变为 **已保存** 即可，不影响上面的数据表连接。之后扫描发现潜在爆款、批量分析完成或余额不足时，系统都会通过这个机器人推送消息。

## 配置模板 AI 字段（选用）

<Callout type="note">
  飞书 AI
  字段用于进一步分析和二创：视频转文字、脚本分析、评论分析、改写仿写。**普通数据同步不需要这些字段**——先把采集和同步跑通，确实要批量逐字稿、分析或改写时再配。免费额度和计费规则以服务商当前页面为准。
</Callout>

### 文本生成

脚本分析、评论分析、二创改写仿写这三个字段都用 **文本生成** 字段捷径，默认模型是火山引擎的 **Doubao-Seed-2.0-pro**，每个模型赠送 50 万 Token。三个字段的账号配置方式完全一样，申请一次凭证给三个字段共用即可。

2. 在控制台右上角头像 → **账号管理 → 实名认证**，选 **个人认证** 完成认证。

### AI 输出是 Markdown？装个渲染插件

脚本分析、评论分析这些字段的输出是 Markdown 源码，直接看不方便。在多维表格右上角 **插件** 入口打开插件市场，搜 **Markdown**，安装免费的 **Markdown 内容渲染**（点单元格实时渲染）。安装后从插件的 **…** 菜单选 **固定至侧边栏**，之后点任意单元格就能看到渲染效果。
