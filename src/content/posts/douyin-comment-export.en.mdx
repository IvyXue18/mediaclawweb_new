## Why export Douyin comments at all

A single comment carries far more signal than a like. But Douyin's comment section loads one row at a time — a few hundred per video, thousands across ten videos — and reading them by hand is both impossible and misleading: you can't tell which signal is a shared, recurring problem and which is a one-off. Export the comments into a table and you can finally filter, sort, and cluster them by theme — turning "users seem to care about price" into "37 comments are asking how much it costs."

## Why Douyin comments never all load

This is the part people trip on the most — and it's the same on Xiaohongshu.

Comments are **lazy-loaded**: they only appear as you scroll down, section by section, and a scraper can't grab what hasn't loaded yet. So scrolling the comment section fully before you collect is what decides whether you get them all.

Two more things to expect:

- The extension has a **cap on how many comments it detects in one pass** — up to about 500 per video, so the tens of thousands on a viral video won't come out in a single run. Collect in batches if you need to.
- The web version already orders comments **semi-randomly** (top-liked or newest float up). In practice, a random few hundred is usually enough to surface the vast majority of the real problems — more isn't always better. Sample a few hundred from high-volume videos; pull everything from smaller ones.

## FAQ

**Is Douyin comment collection free? Do I need to log in?**

Comment collection is free and unlimited. It runs as a Chrome extension inside your own browser and only collects what you can already see on the Douyin web page.

**How many Douyin comments can I export at once?**

Up to about 500 per video, per pass — check the extension's on-screen count. Comments are lazy-loaded, so scroll the section fully before collecting; batch it for very large videos.

**What fields do exported Douyin comments include?**

Typically the comment text, commenter nickname, commenter profile link, and like count — exportable to CSV or synced to a Lark Base (exact fields as shown in the extension).

**Which platforms are supported?**

Both Douyin and Xiaohongshu, with the same collection, export, and lead-filtering flow.

**Can I collect comments on private Douyin accounts?**

Only within the platform's visibility limits — if you can't see it on the Douyin web page, the tool can't pull it either.
