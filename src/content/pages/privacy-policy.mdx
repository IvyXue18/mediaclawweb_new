# MediaClaw Privacy Policy

Updated: July 13, 2026
Effective: March 7, 2026

Thank you for using the **MediaClaw website and browser extension** (collectively, "MediaClaw"). This policy explains how we collect, use, store, and protect your information when you use MediaClaw.

If you do not agree with this policy, please stop using the website and uninstall the Extension.

---

## 1. Information We Collect

### 1.1 Account, Activation, and Authorization Information

When you create a MediaClaw website account, we collect the name and email address or mainland China phone number that you provide. A phone number is converted into an internal account identifier so that you can register and sign in with a password; MediaClaw does not send an SMS or treat the phone number as ownership-verified unless a separate verification feature is introduced and disclosed. Your password is processed using a one-way password hash and is not stored in plaintext.

When you enter an activation code or order number in the Extension for authorization, we collect the following information and send it to the MediaClaw backend server:

- **Activation code / order number** (`code`): The authorization credential you enter, formatted locally before transmission
- **Device identifier** (`clientUuid`): A unique UUID randomly generated locally upon first installation, used to identify the current browser environment
- **Environment label** (`clientLabel`): Automatically detected from the browser User-Agent, e.g., `Chrome on macOS`
- **Extension version** (`appVersion`): The currently installed version of the Extension

This information is used to complete license verification and manage device binding (each activation code supports up to 2 independent browser environments by default).

### 1.2 Lark Base Target Configuration (sent when sync is triggered)

When you configure and initiate a Lark Base sync, the following configuration is sent with the sync request to the MediaClaw backend server:

- Lark Base App Token (`feishuAppToken`)
- Target table name or table ID (`tableId`, `bloggerProfileTableName`, `bloggerNotesTableName`, `keywordNotesTableName`)

This configuration is **used solely to write collected data into the Lark Base table you specify** and will not be stored in MediaClaw's server-side database.

> **Note**: Configuration is stored in your local browser (`chrome.storage.local`) by default. We do not offer cloud configuration sync; configuration data is not automatically uploaded to our servers.

### 1.3 Collected Data (Browser Local Storage)

When you actively trigger a collection on the Xiaohongshu web app, the Extension stores the results in your local browser (`chrome.storage.local`), which may include:

- **Note information**: Title, link, author nickname, content, hashtags, likes/saves/comments count, publish time, image links, video links, cover image, etc.
- **Creator information**: Nickname, Xiaohongshu ID, profile link, avatar link, follower count, bio, and other public information
- **Search / keyword results**: Keywords, search result lists (including note links, cover images, titles, authors, and like counts)
- **Comment information**: Commenter nickname, commenter profile link, comment content, comment like count

**Important notes:**

- The Extension **does not read the `chrome.cookies` API** and does not actively capture cookies from any platform.
- Collected data is stored only on your local device before you initiate a sync and **is not automatically uploaded to our servers**.

### 1.4 Sync History and Runtime State (Browser Local Storage)

The Extension stores the following runtime data locally:

- **Sync history**: Historical sync records including sync time, sync type, success/failure status, debug links, etc. (up to approximately 200 entries retained)
- **Runtime state**: Current page type, collection progress, recently active tab ID, etc.
- **Authorization state**: Local verification status of the activation code, most recent verification time (the activation code is not stored in plain text; only the verification result and encrypted digest are stored)

### 1.5 Download and Export Actions

When you click "Export CSV" or "Download attachments," the Extension generates files locally using the browser's download capability. This action is explicitly triggered by you; files are saved to your local device and do not pass through our servers.

### 1.6 Website Analytics and Attribution

When you visit the MediaClaw website or perform key product actions, we collect limited analytics and attribution data, which may include:

- A randomly generated anonymous browser ID and session ID
- Page path, landing page, and referring website origin/path
- Campaign parameters such as `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term`, `source`, `ref`, and `via`
- A normalized acquisition channel and attribution confidence
- Key events such as page views, pricing or download actions, registration, checkout, and payment success
- Account ID after you sign in, where needed to connect product activity with registration or payment results

MediaClaw stores first-touch and last-non-direct attribution context in browser local storage and a first-party cookie for up to 90 days. An attribution snapshot may also be stored with an order when checkout begins. This is used to understand product performance and campaign effectiveness, connect acquisition sources with registrations and revenue, prevent abuse, and improve MediaClaw. We do not use third-party advertising cookies for this purpose and do not sell this data to advertisers.

### 1.7 Information We Do Not Collect

- **No collection** of bank card numbers, payment passwords, or other financially sensitive information
- **No collection** of login passwords for any platform
- **No capture** of browser cookies (the `chrome.cookies` API is not called)
- **No recording** of full keystrokes, mouse movements, scrolling sessions, or page DOM replays
- **No collection** of any personal information unrelated to the Extension's functionality

## 2. How We Use Your Information

Information we collect is used only for the following purposes:

- **License verification and device management**: Verifying activation code validity and managing the number of bound devices per activation code
- **Data sync relay**: Forwarding collected data from syncs you initiate to the Lark Base table you specify
- **Collection feature support**: Executing collection logic in your currently active Xiaohongshu tab and caching results locally
- **Export and download**: Responding to your explicit actions to generate CSV files or download attachments locally
- **Troubleshooting**: Using local sync history to help you diagnose sync failures
- **Product analytics and attribution**: Measuring website and product performance and connecting acquisition sources with registrations, orders, and revenue

## 3. Storage and Security

### 3.1 Local Storage (Browser Side)

The following data is stored in your browser extension's local storage (`chrome.storage.local`):

| Data Type           | Storage Location | How to Clear                             |
| ------------------- | ---------------- | ---------------------------------------- |
| Runtime state       | Local            | In-extension cleanup / Uninstall         |
| Authorization state | Local            | In-extension cleanup / Uninstall         |
| Lark Base config    | Local            | In-extension cleanup / Uninstall         |
| Collected data pool | Local            | One-click clear in extension / Uninstall |
| Sync history        | Local            | One-click clear in extension / Uninstall |

You can delete all local data via the extension's built-in cleanup function, browser extension data clearing, or by directly uninstalling the Extension.

The website also stores attribution context in browser local storage and a first-party cookie for up to 90 days. You can remove it by clearing site data for the MediaClaw website.

### 3.2 Server-Side Storage

We store the minimum information necessary to operate and improve MediaClaw on our backend servers:

- Activation code / order number status (valid / expired / frozen)
- Device UUID binding associations and most recent verification time
- Account profile and login identifier (name and email address or phone-backed internal identifier) plus the password hash required for authentication
- Limited analytics event records, including anonymous/session identifiers, page and campaign attribution data, event type, and event time
- Registration, order, and payment attribution snapshots used to calculate conversion and revenue by source

**Sync relay data (Lark Base configuration + collected payload) is handled on a "process and forward" basis and is not retained long-term in our server-side database.**

### 3.3 Security Measures

- Activation codes are stored locally as a non-plaintext digest; they are never stored in plain text
- All API communication in production environments uses HTTPS encryption
- The server employs access control and data minimization principles
- We have made reasonable efforts to protect data security, but cannot guarantee 100% security in all circumstances. Data breaches resulting from user-side causes (e.g., device infected with malware, weak passwords, account compromise) are outside the scope of this policy

## 6. Your Rights

In accordance with applicable laws and regulations, you have the following rights:

- **Right to be informed**: The right to know how we process your information (i.e., this policy)
- **Right of access**: You may view locally cached collected data, configuration, and sync history in the Extension at any time
- **Right to rectification and deletion**: You may modify Lark Base configuration or clear collected data and sync history in the Extension at any time
- **Right to restrict processing**: You may stop the sync function and use collected results locally only; data will not leave your device
- **Authorization release request**: If device binding slots are exhausted due to a device change or browser reinstallation, you may contact us to manually release a slot
- **Right to withdraw consent**: You may uninstall the Extension and clear extension data at any time to withdraw your consent to this policy
- **Website data controls**: You may clear MediaClaw website data in your browser; you may also contact us to request access to or deletion of server-side data that can reasonably be associated with you, subject to legal retention requirements
