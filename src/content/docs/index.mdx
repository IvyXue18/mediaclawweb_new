## Start Here

MediaClaw helps content teams collect Xiaohongshu and Douyin posts, comments, media, transcripts, and image text into a reusable data pool. Use this page as the public tutorial entry while the full docs tree is being migrated.

### 1. Install the extension

Open the [download page](/download) and choose the Chrome/Edge store path first. If store access is unavailable, use the offline package on the same page and follow the install steps there.

### 2. Activate or claim a trial

After signing in, claim a short trial from the [welfare center](/welfare) or buy a plan on [pricing](/pricing). Enter the activation code in the extension when prompted.

### 3. Collect platform data

Use these entry guides for the core public workflows:

- [Xiaohongshu data collection](/xiaohongshu/scraper)
- [Xiaohongshu comments](/xiaohongshu/comments)
- [Xiaohongshu image text extraction](/xiaohongshu/image-text)
- [Xiaohongshu video transcripts](/xiaohongshu/transcript)
- [Douyin data collection](/douyin/scraper)
- [Douyin comments](/douyin/comments)
- [Douyin image text extraction](/douyin/image-text)
- [Douyin video transcripts](/douyin/transcript)

### 4. Export and sync

Collected records can be copied, exported as CSV/Markdown, or synced to Lark Base through the [Lark integration](/features/feishu-integration). Use Markdown export when you want records to flow into a knowledge base or AI review workflow.

### 5. Diagnose a failed run

If collection, export, sync, transcript extraction, or image text extraction fails, copy the diagnostic information from the extension and keep the original page URL. It helps identify whether the issue happened during page detection, collection, media loading, AI processing, export, or sync.

### Need a quick path?

Install from [download](/download), collect one Xiaohongshu or Douyin record, export it as Markdown, then try transcript or image text extraction on that record.
