社媒虾 MediaClaw 里有三条独立的创作途径。它们**不共享中间产物**：工作台的选题库、飞书的 AI 字段、Agent 的本机配对，彼此不互通。所以尝试后选定一条适合自己的创作路径就行，不需要在三者之间来回切换。

<Callout type="important">
  采集到公开内容不等于获得转载或商用授权。三条途径都只负责整理素材和生成初稿，不能替你判断版权与合规风险；发布前仍需人工确认。
</Callout>

## 三条路的差异

|                  | 在 AI 工作台创作    | 同步飞书批量分析和创作 | 用 Agent 结合知识库创作       |
| ---------------- | ------------------- | ---------------------- | ----------------------------- |
| 一次处理多少     | 一篇                | 一批（整列记录）       | 一批，且可连续执行多个步骤    |
| 提示词能不能改   | 不能，流程固定      | 能，在字段里直接改     | 能，直接在对话里说            |
| 前置成本         | 无，装完插件就能用  | 配飞书模板 + 模型 Key  | 装 Agent 接入包 + 本机配对    |
| 费用             | 生成消耗积分        | 按你自己的模型用量计费 | 用当前 Agent 的模型，不计积分 |
| 怎么结合你的业务 | 创作档案 + 账号风格 | 改提示词               | 读取你的本地知识库            |
| 最适合           | 单篇出稿最快        | 团队协作、留痕、批量   | 模糊目标、跨平台、长期资产    |

## 在 AI 工作台创作

从单篇拆解或账号研究拿到选题，收藏进选题库，在生成弹窗里确认简报、选图文或视频、按需带上你的业务信息，生成一版可继续修改的稿件。流程是固定的，不需要写提示词。

**什么时候不要用它**：手上只有一段自己的口播稿或旧稿，还没有任何研究资产——工作台的入口都从选题起，这种情况走飞书或 Agent。

继续阅读：[在 AI 工作台创作](/docs/create/plugin-workbench)。

## 同步飞书批量分析和创作

把采集到的作品同步进飞书模板，用模板里的 AI 字段对整列记录批量跑脚本分析或二创改写。字段里的提示词是完全可改的，可以按自己的业务重写。

**什么时候不要用它**：只想快速出一篇稿——配模板和模型 Key 的成本大于收益。

继续阅读：[同步飞书批量分析和创作](/docs/create/feishu-batch)。

## 用 Agent 结合知识库创作

Agent 可以同时读取 MediaClaw 里的研究资产和你授权的本地文件夹——品牌手册、产品文档、历史稿件、访谈记录。平台证据和你自己的事实由它组合，输出也不局限于一篇稿件。

**什么时候不要用它**：还没完成安装和配对，或者这次只是想按固定流程出一篇标准图文。

继续阅读：[用 Agent 结合知识库创作](/docs/create/agent-creation)。

## 三条路都能带上你自己的业务

生成的稿子"不像自己写的、没有业务信息"不是模型能力问题，是没有把你的事实喂进去。三条路各有自己的做法，选哪条都能解决：

- **工作台**：在生成弹窗里展开「植入我的业务」填创作档案，再选一个账号风格。档案回答"为谁、写什么业务、希望产生什么行动"，风格回答"怎么写"。
- **飞书**：直接改字段里的提示词，把角色、目标人群、必须提到和不能说的内容写进去。
- **Agent**：把品牌资料和历史稿件所在的目录授权给它，让它区分平台证据、你的产品事实和它自己的推断。
