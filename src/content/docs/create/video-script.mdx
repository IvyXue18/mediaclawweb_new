选定一个选题后，用飞书 AI 模板里的**脚本分析**字段，对一段口播逐字稿进行结构化分析和优化，产出更符合"爆款视频素质"的脚本版本。

## 前置条件

先完成[飞书模板 AI 字段](/docs/settings/feishu-template)里的文本生成配置，并已经通过[提取视频逐字稿](/docs/collect/transcript)拿到一段口播逐字稿。

## 分析维度

脚本分析会从以下 5 个维度打分并给出理由，最后输出优化版本：

1. **目标受众匹配度**：是否聚焦目标群体的痛点 / 利益点
2. **吸引力（前 2 秒）**：开头是否足够抓人
3. **期待感（前 4~5 秒）**：是否制造悬念或预期
4. **实用价值**：是否提供明确的干货或方法论
5. **节奏与语言表达**：是否通俗易懂、口语化、节奏感强

## 提示词模板

可以根据自己的要求修改这个提示词：

```plaintext
请你以短视频策划专家的视角，从以下几个维度对这段口播脚本 进行全面分析和优化建议：
1. 目标受众匹配度：脚本是否聚焦目标群体的痛点/利益点？能否让用户一看就觉得"这和我有关"？
2. 吸引力（前2秒）：开头是否足够抓人？是否具备黄金开场、能迅速吸引用户注意？
3. 期待感（前4~5秒）：是否制造了悬念或预期？有没有激发"我想继续看下去"的情绪？
4. 实用价值（整体内容）：脚本是否提供了明确的干货、实用信息或方法论？观众看完能否获得"对我有用"的收获感？
5.节奏与语言表达：语言是否通俗易懂、口语化、节奏感强？是否有拖沓或冗余？
请按以上 5 点打分并逐一说明理由，最后给出整体优化建议，并根据原始脚本生成一个更符合"爆款视频素质"的优化版本。
```
