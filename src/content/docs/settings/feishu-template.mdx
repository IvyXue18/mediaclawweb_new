本页负责说明飞书模板能做什么，以及第一次使用时如何建立 MediaClaw 与目标多维表格的连接。配置通常只做一次；日常选择数据并发起同步，请查看[同步到飞书多维表格](/docs/collect/feishu-sync)。

## 模板能做什么

| 能力           | 用途                                                             | 是否需要额外配置       |
| -------------- | ---------------------------------------------------------------- | ---------------------- |
| 六类数据表     | 接收单篇作品、关键词作品、博主信息、博主作品、评论客资和监控内容 | 完成基础连接即可       |
| 链接转附件     | 把图片等远程链接转换成表格内可查看附件                           | 选填，需要字段服务 Key |
| 视频转文字     | 批量提取视频口播内容                                             | 选填，需要语音识别服务 |
| 文本分析与生成 | 脚本分析、评论需求分析、改写仿写                                 | 选填，需要文本模型服务 |
| 监控通知       | 将命中结果写入监控表，并通过飞书群机器人发送通知                 | 选填，需要 Webhook     |

<Callout type="note">
  普通数据同步不需要配置外部 AI
  字段。先完成基础连接并测试写入；确实需要批量逐字稿、分析或改写时，再配置对应能力。
</Callout>

## 第一步：复制模板并移动到云盘

打开 MediaClaw 飞书模板，点击**使用该模板**，复制到自己的飞书中。

<ImagePlaceholder caption="复制 MediaClaw 飞书多维表格模板截图" />

复制好后，把模板**移动到云盘**。

<Callout type="danger">
  不要放在知识库，也不要放在文档库。放在这两处时文档链接是 wiki
  链接，插件无法正常同步，必须移动到云盘拿到 base 链接。
</Callout>

<ImagePlaceholder caption="把模板移动到云盘的截图" />

## 第二步：设置可写权限

模板权限必须设置成**互联网获得链接的人可编辑**：

| 设置                          | 结果                              |
| ----------------------------- | --------------------------------- |
| 互联网获得链接的人 **可编辑** | ✅ 正确                           |
| 互联网获得链接的人 **可阅读** | ❌ 无法写入数据                   |
| 组织内获得链接的人可编辑      | ❌ 插件以链接访问，非组织成员身份 |

<ImagePlaceholder caption="设置互联网可编辑权限的截图" />

当前同步方式要求使用可直接访问的多维表格文档。权限不足时，即使链接正确也无法写入。团队使用时，还要控制谁能查看和编辑采集数据。

## 第三步：填写 base 文档 URL

1. 打开目标多维表格。
2. 复制浏览器地址栏中的文档链接。
3. 打开插件设置 → **数据同步**。
4. 将链接粘贴到 **飞书多维表格文档 URL**。
5. 确认链接路径中是 **/base/**，不是 **/wiki/**。

示例结构：

- 正确：`https://example.feishu.cn/base/...`
- 错误：`https://example.feishu.cn/wiki/...`

<ImagePlaceholder caption="飞书 base 链接与插件文档 URL 输入框对照截图" />

## 第四步：核对数据表名称和字段

插件可以配置六类数据表：

- 单笔记表名
- 关键词笔记表名
- 博主信息表名
- 博主笔记表名
- 客资表
- 监控表名

名称必须与飞书左侧实际数据表名称完全一致。可以新增自己的视图和辅助字段，但不要修改模板已有字段名称、字段类型或必需的数据表；如果改了数据表名称，插件配置也要同步修改。

<ImagePlaceholder caption="插件 6 类数据表名称与飞书左侧表名对照截图" />

支持团队表格槽位的版本，可以为不同项目保存多个目标并添加备注。每台设备可以独立选择当前要同步的表格，开始同步前务必再次确认。

## 第五步：配置飞书通知（选填）

如果需要接收账号监控等消息，在飞书群添加自定义机器人，复制 Webhook，并填入 **飞书机器人 Webhook**。该字段与数据表连接分开保存；不填写不会影响普通表格同步。

<ImagePlaceholder caption="飞书自定义机器人 Webhook 与插件通知配置截图" />

<Callout type="danger">
  Webhook
  相当于群机器人发送凭证，不要公开到文档、截图、代码仓库或聊天群。泄露后应立即在飞书重新生成。
</Callout>

## 第六步：配置模板 AI 字段（选填）

模板预置的外部字段可以按需启用。免费额度和计费规则可能调整，以服务商当前页面显示为准。

| 字段能力   | 用来做什么                       | 服务来源           | 示例额度       |
| ---------- | -------------------------------- | ------------------ | -------------- |
| 链接转附件 | 把图片链接转成附件，方便直接查看 | 第三方字段捷径     | 500 次         |
| 视频转文字 | 提取视频口播内容                 | 阿里云百炼         | 每月 10 小时   |
| 文本生成   | 脚本分析、评论分析、改写仿写     | 火山引擎等文本模型 | 以所选模型为准 |

### 链接转附件

根据字段内说明获取服务 Key。当前模板使用的字段服务可参考 [Field Shortcut](https://fieldshortcut.com/zh)。

<ImagePlaceholder caption="链接转附件字段配置截图" />

### 视频转文字

在[阿里云百炼控制台](https://bailian.console.aliyun.com/cn-beijing#/home)获取所需参数，再填入模板中对应的视频转文字字段。

<ImagePlaceholder caption="阿里云百炼参数获取与视频转文字字段配置截图" />

### 文本分析与生成

模板示例使用文本模型完成脚本分析、评论分析和二创改写。可以根据团队使用的模型替换字段捷径，并修改提示词模板。

<ImagePlaceholder caption="文本模型参数与脚本分析字段配置截图" />

复制模板后，部分 AI 字段出现感叹号，通常是因为字段中仍是模板测试账号，需要换成自己申请的 Key。AI 输出为 Markdown 时，可以在多维表格插件市场安装 Markdown 渲染插件改善阅读体验。

<Callout type="danger">
  API Key
  不要放进公开文档、截图、代码仓库或共享聊天。怀疑泄露时，应立即到对应服务商控制台撤销并重新生成。
</Callout>

## 第七步：保存并测试

1. 点击表格连接卡片右上角的保存按钮。
2. 回到一个作品详情页，先采集一条字段较完整的记录。
3. 在数据池点击 **同步飞书**。
4. 到对应数据表确认记录和关键字段。
5. 需要使用 AI 字段时，再用一条记录分别测试转写或分析，不要直接运行整列。

## 配置完成后怎么使用

- [同步到飞书多维表格](/docs/collect/feishu-sync)：日常把数据池记录写入模板。
- [视频转文字：提取逐字稿](/docs/collect/transcript)：补齐视频原始内容。
- [从评论问题中发现选题](/docs/topics/comment-ideas)：把评论证据转成选题方向。
- [持续监控对标账号](/docs/benchmark/monitoring)：配置监控规则和通知。
- [选择插件或 Agent 创作](/docs/create/overview)：把结构化数据继续交给创作流程。

## 常见问题

- **保存后同步不到**：检查 base 链接、文档权限、表名和字段结构。
- **数据写到了另一张表**：确认当前团队表格槽位和实际查看的文档一致。
- **只有标题和点赞，没有正文或附件**：先执行采集增强，再同步。
- **Webhook 没消息**：先确认任务本身有命中，再检查机器人是否仍在群中、Webhook 是否完整。
- **AI 字段出现感叹号**：替换模板测试账号的 Key，并检查外部服务额度。
- **部分成功、部分失败**：到执行明细查看每条结果和调试链接，不要直接反复同步全部数据。

详细排查见[常见问题](/docs/reference/faq)。
