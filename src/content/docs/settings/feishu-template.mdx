### 检查表名

插件的 **飞书归档目标配置** 里有六类数据表名称，必须与飞书模板左侧的实际数据表名称一一对应（排列顺序可以不同）：单笔记采集、关键词笔记采集、博主信息表、博主笔记采集、评论区客资采集、监控内容表。

<DocImage

<Callout type="danger">

</Callout>

<Callout type="important">
**这些 AI 字段不是 MediaClaw 开发的功能。** 能力本身由飞书多维表格的「第三方字段捷径」和背后的模型服务商（阿里云百炼、火山引擎豆包、字段捷径服务商等）提供；本节只讲怎么把这些现成能力组装进模板。你可以按自己的需求换模型、改提示词、加字段——这也是飞书多维表格灵活的地方。

**字段问题找谁：** 字段的报错、识别 / 生成效果、免费额度和计费，都归对应服务商，请查服务商的文档或联系其客服——这些账号和字段都配置在你自己的飞书里，MediaClaw 没有权限、也无法代为调试。只有「插件采集 → 数据池 → 同步飞书」这条链路上的问题才需要找 MediaClaw，排查步骤见[常见问题](/docs/settings/faq)。

**关于额度：** 这些能力根据自己的需求选配，下标每项能力都有服务商各自发放的免费额度，日常用量一般够用；超出部分按各服务商的价格从你自己的账号结算，不占用插件的积分额度。好处是用量和花费都在你自己手里，透明可控（正常来说，不同服务商各充 5 块钱也能用很久）。

</Callout>

**第 2 步 · 开通豆包模型并创建推理接入点**

1. 打开[火山方舟控制台-模型广场](https://console.volcengine.com/ark/region:cn-beijing/model?view=CARD_VIEW)，找到 **Doubao-Seed-2.0-pro** 模型页，点 **API 接入**，在「快捷 API 接入」的 STEP 2 里选择模型并点 **开通模型**（选 pro）。
2. 到 **在线推理 → 自定义推理接入点**，点 **创建推理接入点**，填名称、推理模式选 **指定单一模型**，**添加模型** 选刚开通的 Doubao-Seed-2.0-pro。
3. 接入模式选 **按 Token 付费**，点 **创建并接入**。

### Markdown渲染插件
