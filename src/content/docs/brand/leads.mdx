评论客资筛选用于从公开评论中留下明确咨询、询价、求链接或服务需求。它不会自动判断联系方式，也不会替你完成销售跟进。

## 前置条件

1. 已完成激活码验证。
2. 在单篇采集或采集增强中开启 **附加评论**。
3. 设置评论加载上限，让目标评论实际进入采集结果。
4. 在插件设置 → 采集与筛选 → **评论客资筛选** 中配置规则。
5. 需要同步飞书时，已配置客资表。

## 配置筛选规则

- **客资关键词**：逗号分隔，例如“想买、怎么买、求链接、多少钱”。
- **客资 IP**：逗号分隔，例如“广东、北京”。

命中任一关键词即可通过关键词条件。如果同时配置了 IP，评论还必须与其中一个 IP 属地完全匹配；关键词与 IP 是“且”的关系。只配置其中一类规则时，则只按该类筛选。

## 采集并筛选

1. 打开目标作品详情页，加载可见评论。
2. 开启 **附加评论** 和 **评论客资筛选**。
3. 开始采集单篇作品，或在搜索/账号采集增强中补采评论。
4. 等待插件按当前规则筛选命中项。
5. 在导出或同步前抽查评论原文、用户名称、发布时间和 IP 属地。

<ImagePlaceholder caption="作品采集中的「附加评论」和「评论客资筛选」开关截图" />

<Callout type="note">
  客资筛选只处理已经采集到的一、二级可见评论。页面未加载、评论被删除或平台未展示
  IP 时，插件无法补出这些信息。
</Callout>

## 导出或同步

- 本地导出可选择评论客资 CSV 或 Markdown，便于人工去重和分配。
- 同步飞书时，命中项会写入配置的客资表。
- 建议保留原作品链接、评论原文、命中关键词和采集时间，方便回溯。

同一用户可能在多篇作品下重复留言。当前流程不应被视为完整 CRM，正式跟进前请按用户、评论内容和作品链接人工去重。

## 后续跟进

- 先区分真实咨询、泛讨论、调侃和广告。
- 按意向类型、地区、产品和紧急程度分组。
- 只在平台规则和隐私要求允许的范围内联系。
- 不要依据 IP 属地推断精确位置或敏感个人信息。
- 将联系结果写回你自己的飞书或 CRM。

<Callout type="danger">
  公开评论不等于同意被营销。请遵守平台规则、个人信息保护要求和团队内部的数据访问规范。
</Callout>
