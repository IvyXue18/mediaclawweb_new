## 从这里开始

MediaClaw 社媒虾用于采集小红书和抖音的笔记、视频、评论、媒体素材、视频逐字稿和图片文字，并沉淀到可复制、可导出、可同步的数据池里。完整文档树迁移前，这一页先作为公开教程入口。

### 1. 安装插件

先打开[下载页](/download)，优先使用 Chrome / Edge 商店安装。如果商店访问不稳定，再使用同一页面的离线安装包和安装步骤。

### 2. 激活或领取试用

登录后可以在[福利中心](/welfare)领取短期试用，也可以在[价格页](/pricing)购买正式方案。拿到激活码后，按插件提示填入即可。

### 3. 开始采集平台数据

常用公开教程入口：

- [小红书数据采集](/xiaohongshu/scraper)
- [小红书评论采集](/xiaohongshu/comments)
- [小红书图文文案提取](/xiaohongshu/image-text)
- [小红书视频逐字稿](/xiaohongshu/transcript)
- [抖音数据采集](/douyin/scraper)
- [抖音评论采集](/douyin/comments)
- [抖音图文文案提取](/douyin/image-text)
- [抖音视频逐字稿](/douyin/transcript)

### 4. 导出和同步

采集完成后，可以复制记录、导出 CSV/Markdown，也可以通过[飞书多维表格同步](/features/feishu-integration)进入团队协作流程。需要沉淀到知识库或交给 AI 复盘时，优先使用 Markdown 导出。

### 5. 排查失败任务

如果采集、导出、同步、视频逐字稿或图片文字提取失败，请在插件里复制诊断信息，并保留原始页面链接。诊断信息可以帮助判断问题发生在页面识别、采集、媒体加载、AI 处理、导出还是同步阶段。

### 想最快跑一遍？

从[下载页](/download)安装插件，采集一条小红书或抖音记录，导出 Markdown，然后在这条记录上试一次视频逐字稿或图文文案提取。
