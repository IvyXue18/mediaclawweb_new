账号监控用于持续发现对标账号前一天发布的新作品，并在观察期内判断是否达到你设置的点赞阈值。它适合跟踪少量重点账号，不适合无差别加入大量主页。

## 加入监控

1. 打开要跟踪的抖音或小红书账号主页。
2. 打开 MediaClaw，进入账号监控。
3. 确认当前账号名称与主页链接正确。
4. 点击 **加入监控**。
5. 回到监控列表，检查账号是否已经出现；需要立即验证时，可点击 **立即执行扫描**。

## 设置监控规则

在插件设置的 **账号监控规则** 中配置：

- **执行时点**：每天固定什么时间扫描订阅监控的账号并发送分析报告
- **发布时间范围**：当前固定查找前一天发布的作品。
- **观察期**：可选 24、48 或 72 小时。
- **点赞筛选**：观察期内超过该值的作品视为潜在爆款并进入汇报。如果为 0，则意味着所有更新内容都会汇报；不为 0，表示从发布到执行扫描时点，对标账号的更新内容需要达到点赞数值才会汇报。
