设置中心分为数据同步、采集与筛选、监控任务和 Agent 接管。首次使用建议保留默认采集节奏，只配置当前工作流真正需要的项目。

## 数据同步

在 **数据同步** 中配置：

- 飞书多维表格文档 URL。
- 单笔记、关键词笔记、博主信息、博主笔记、客资和监控数据表名称。
- 可选的飞书机器人 Webhook。
- 支持团队表格槽位的版本，还可以为不同项目保存多个同步目标，并在本机选择当前目标。

表格连接需要点击保存按钮；Webhook 会显示自动保存状态。完整配置见[飞书模板配置](/docs/settings/feishu-template)。

## 采集与筛选

### 采集策略

- **同步范围**：推荐“仅同步当前页面缓存区未同步数据”；切换为全部数据时可能重复处理。
- **补采范围**：推荐“仅补采未补采详情”；全部补采会增加页面访问和耗时。
- **随机等待时间**：默认 3～6 秒，用于连续页面操作之间的随机间隔。
- **批量任务冷却**：默认 2～4 秒，用于批量关键词、批量博主等任务之间。
- **无新增超时**：默认 3 秒，连续没有新内容时结束当前加载阶段。
- **最大采集时长**：默认 600 秒，避免任务无限运行。
- **页面打开超时**：默认 90 秒，超过后将本次补采标记为失败。
- **详情页/博主页打开后缓冲**：默认各 2 秒，让正文、评论或作者指标完成渲染。

<Callout type="note">
  默认值兼顾成功率和访问节奏。页面加载较慢时，可以适当增加等待和缓冲；不要为了提速把等待时间持续调低。

### 评论客资筛选

填写逗号分隔的客资关键词和可选 IP 属地。两类规则都存在时必须同时命中。详细说明见[客资线索](/docs/brand/leads)。

## 监控任务

账号监控规则包括：

- 每天的执行整点，实际开始最多可能延迟约 1 小时。
- 固定查找前一天发布的作品。
- 24、48 或 72 小时观察期。
- 潜在爆款的最低点赞阈值。

修改后会作用于已加入监控的账号。平台扫描会消耗积分，实际成本以任务记录和当前配置为准。

## Agent 接管

Agent 接管用于连接本机 Agent 客户端与当前浏览器扩展。接入后，Agent 可以按你的目标调用插件采集、读取数据池与 AI 工作台资产，并继续完成研究和创作。

### 本机调用与连接状态

1. 先在 Agent 客户端安装 **MediaClaw 内容研究** 接入包。
2. 在扩展中验证有效会员激活码。
3. 开启 **允许本机 Agent 调用社媒虾**。
4. 首次连接时核对设备并点击 **批准配对**。
5. 设置页会显示未开启、等待连接、等待批准、已连接或连接异常；异常时可使用重连。

完整安装、配对和排障步骤见[接入 Agent，结合知识库创作](/docs/create/agent-workflow)。

<Callout type="important">
  Agent 只通过当前设备的本机连接调用扩展。激活码、Cookie 和 Token
  仍由扩展保存，不需要也不应该发送给 Agent。
</Callout>

### 视频逐字稿处理方式

- **自动选择**：先检查本地转录条件；需要改用云端时展示预计积分，确认后继续。
- **本地转录**：在本机处理，不使用积分；需要提前配置本地转录环境。本地条件不满足时会保留任务和错误提示。
- **云端转录**：无需本地环境；每次先展示预计积分，确认后再开始。

本地转录设置只对拥有相应权益的账号显示。配置本地环境时，可以复制设置页提供的安装检查提示词交给 Agent；执行系统安装命令前仍应核对命令、下载量和磁盘占用。

## 本地数据与清理

采集记录和任务进度会保存在插件本地缓存。数据池的 **更多批量操作** 中可以清理已同步数据或清空当前页面缓存：

- **清理已同步数据**：保留采集进度，移除已经同步的缓存记录。
- **清空当前页面缓存**：同时重置该页面的采集进度。

执行前先确认重要数据已经导出或同步。更换浏览器、清理扩展数据或卸载插件，也可能影响本地记录。
