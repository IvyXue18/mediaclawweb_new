## 支持哪些 Agent

| 宿主Agent | 状态 | 安装时你要做什么                                                                                                                              |
| --------- | ---- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| Codex     | 可用 | 不用动手。把安装提示词发给它，它自己一路装到底                                                                                                |
| WorkBuddy | 可用 | 不用动手。把安装提示词发给它，它自己一路装到底                                                                                                |
| 豆包工作  | 可用 | 豆包没有自动安装入口，需要你手动在「技能 · 连接器 · 伙伴 → 本地电脑 → STDIO」里新建一个连接。Agent 会把要填的内容整理好给你，照着粘贴保存即可 |

## 第一步：复制安装提示词

1. 打开社媒虾扩展 → **右上角系统配置 → Agent 接管**。
2. 打开 **允许本机 Agent 调用社媒虾**。
3. 展开下方的 **连接 Agent**，找到你要用的宿主，点 **复制安装提示词**。

这段提示词里已经写好了官方来源、当前宿主的安装命令、修复步骤和连接续接任务。你不需要看懂它，也不需要修改。

## 第二步：发给 Agent，让它自己装

在对应的宿主Agent里新建一个对话，把刚才复制的内容原样发送。接下来这些都由 Agent 完成：

- 识别当前宿主，注册官方 marketplace 并安装接入包。
- 识别你的系统和芯片（Windows／macOS／Linux，x64／ARM64），获取并校验对应的官方运行时。
- 装完后如果当前对话加载不到新工具，它会自己开一个续接对话，把任务带过去。

## 第三步：回插件批准配对

Agent 检测到扩展后，插件的 Agent 接管页会出现待批准的设备。

1. 核对设备名称和 **设备指纹**。
2. 点 **批准配对**。
3. 回到 Agent 对话，它会自动复查连接，不需要你回复"已批准"。

## 升级

Agent 的能力也随着插件版本迭代，发布新版本之后，你需要：

1. 在已有的 MediaClaw 对话里直接说 **升级 MediaClaw Agent**。这句话本身就是授权。
2. 它会刷新官方来源、安装、核验版本，进行安装覆盖。
3. **完全退出Agent并重启应用**。
4. 回到原来的对话说一句 **继续**。
5. 它会重新检查状态；只有确认新版本**已激活**，才会宣布升级完成，并自动接着做你之前没做完的事。
