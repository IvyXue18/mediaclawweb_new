MediaClaw 目前支持**小红书**和**抖音**。两个平台使用同一套功能入口和任务流程，教程不会重复拆成两套目录。

## 支持的页面与内容

| 页面或内容类型 | 可以完成的任务                                   |
| -------------- | ------------------------------------------------ |
| 作品详情页     | 采集单篇内容、评论、图片、视频、逐字稿和图片文字 |
| 搜索结果页     | 批量采集搜索结果、研究关键词和爆款方向           |
| 账号主页       | 批量采集账号作品、加入监控、发起账号研究         |
| 数据池记录     | 筛选、导出、同步、单篇拆解和后续研究             |
| AI 工作台      | 账号研究、单篇拆解、选题收藏和内容创作           |

## 主要字段

根据页面公开信息和采集方式，记录可能包含标题、正文、作者、发布时间、链接、互动数据、图片、视频、评论、逐字稿和图片文字。不同平台对互动字段的命名和公开范围可能不同。
