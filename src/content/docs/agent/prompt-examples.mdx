下面每一条都是一次真实的运行：给出的指令可以直接复制，把 `<尖括号>` 里的内容换成你自己的。截图里保留了它采样、报价、确认和交付的完整过程。

配套阅读：[Agent 是什么、接入后谁负责什么](/docs/agent/overview)、[安装、配对与升级](/docs/agent/setup)。

## 一个通用模板

```plaintext
背景：我是谁，服务谁，现在在做什么。
目标：这次要做出什么决定、或交付什么东西。
资料：允许使用哪些 MediaClaw 资产、哪些本地知识库目录，调用哪些已有 skill。
顺序：先研究还是直接写；要不要我中途确认。
输出：形式、数量、平台、长度、语气、要不要标注来源。
边界：不能编造什么，哪些必须我人工确认。
```

## 1. 采集一批评论，读懂需求，转成选题

**什么时候用**：你翻某条爆款的评论区，感觉里面全是选题，但一条条看没头绪。插件里"评论采集"和"评论分析"是分开的两步，还受单轮条数限制。

```plaintext
我发现这条笔记 <作品链接> 的评论区有很多用户提问和需求。
帮我抓取至少 300 条评论，分析整个评论区的用户想法和需求，
再告诉我有哪些可以切入的选题。
```

## 2. 找低粉高赞的对标账号

**什么时候用**：刚起号或换赛道，不想研究几十万粉的大博主——那些打法小账号照搬不了。你想知道同赛道里粉丝几百的号靠什么跑出来。

```plaintext
我做线香赛道，我刚起号，不想只研究几十万粉的大博主。
帮我找这个赛道里的低粉高赞内容，分析它们靠什么跑出来，
再给我一套适合小账号执行的选题方案。
```

## 3. 跨平台主题调研

**什么时候用**：你想知道某个工具或话题最近大家在讲什么新用法，但自己一条条刷小红书和抖音，容易把某个博主的个别演示当成"官方新功能"。

```plaintext
帮我查下小红书和抖音上最近 <关键词> 的最新教程有啥新玩法。
```

## 4. 看某个话题今天的最新内容

**什么时候用**：追一个热点，只想要"今天刚发的"，不要上个月的爆款混进来。

```plaintext
看下今天发布的 <关键词> 相关的小红书内容。
```

其实可以设置一个定时任务每天跑，相当于定时监控了。

## 5. 拆一条视频为什么留人，再改成你能拍的脚本

**什么时候用**：看到一条完播明显很高的视频，想知道它开头怎么抓人、中间怎么不让人划走，并且想要一版自己能直接拍的脚本——不是照抄。

```plaintext
这条视频为什么能让人一直看下去？开头怎么说、后面怎么推进的，
也帮我改成我能拍的脚本：<视频链接>
```

## 6. 把结论写回你自己的知识库

**什么时候用**：这是 MediaClaw 单独做不到的一件事。你想让平台数据和你自己的资料放在一起——要么让它读你的库、找平台上有需求但你没写过的选题，要么把这次的分析直接落进你的本地文档长期留存。

```plaintext
把这些评论整理到 <你的知识库文件路径>，
再分析获取到的 1000 条评论，把结论写到这个文档开头。
```

**它会做什么**：把 1000 条评论（含点赞、地区、时间、主页）整理进你指定的文档，并在开头写入核心结论、主题信号、分歧、未满足需求和内容机会。

**你拿到什么**：一份留在你自己知识库里、可长期复用的分析。反过来也一样——让它先读你的库再研究，就能找出"平台上有真实需求、但你还没写过"的选题。
