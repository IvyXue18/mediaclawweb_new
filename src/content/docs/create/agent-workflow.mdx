接入 Agent 后，你不需要先判断该采关键词、账号、爆款还是评论。只要描述目标和当前问题，Agent 会选择证据路径，调用社媒虾 MediaClaw 采集或读取已有资产，再使用当前 Agent 的模型能力完成分析、选题、策划和成稿。

<Callout type="important">
  Agent 接入包和浏览器扩展是两个安装对象。接入包让 Agent 获得 MediaClaw
  的工具与方法；浏览器扩展继续负责在你当前浏览器中采集、保存和执行任务。只安装其中一个，无法完成接管。
</Callout>

## 接入前准备

- 使用支持 MediaClaw Agent 接入包的 Agent 客户端。
- 在 Chromium 系浏览器中安装并启用社媒虾 MediaClaw 扩展。
- 在扩展中登录，并验证当前有效的会员激活码。
- 保持准备执行采集的浏览器可用；遇到登录或验证码时，需要在浏览器里人工处理。

## 安装与配对

1. 在 Agent 客户端的插件市场搜索 **MediaClaw**，安装 **MediaClaw 内容研究** 接入包。
2. 新建一个 Agent 任务，发送：`检查 MediaClaw 是否已连接，并告诉我当前可以使用哪些能力。`
3. 如果提示尚未检测到浏览器扩展，打开社媒虾扩展的 **设置 → Agent 接管**。
4. 开启 **允许本机 Agent 调用社媒虾**，保持当前 Agent 会话运行。
5. 页面出现当前设备后，核对设备信息并点击 **批准配对**。
6. Agent 会自动复查连接。看到“连接与配对已完成”后，即可直接描述研究或创作目标。

已批准设备会保留配对关系。会员失效时扩展会断开连接并关闭接管；重新验证会员并再次开启即可，通常不需要重新配对。

<Callout type="note">
  激活码只在浏览器扩展内保存和验证。不要把激活码、Cookie、Token
  或模型供应商密钥发给 Agent。
</Callout>

## Agent 比插件内创作多做了什么

### 1. 从模糊目标反推研究路径

你可以直接说“我在做营养师账号，最近选题越来越重复”，Agent 会判断应该先研究关键词、账号、爆款还是评论，并说明证据不足之处，而不是要求你先学会所有功能入口。

### 2. 采集、分析与创作可以连续执行

Agent 可以检查已有资产，避免重复采集；需要新证据时，再调用基础采集、评论、图片文字提取或经你确认后的详情增强。拿到证据后继续完成趋势判断、账号策略、选题、任务书和初稿。

### 3. 可以读取已沉淀的分析资产

Agent 不只读取原始数据池，还可以读取账号分析、单篇拆解、账号风格、选题和已生成内容。它会先定位资产，再读取完整对象，保留来源和证据关系。

### 4. 可以融合你的本地知识库

当 Agent 客户端已经获得你指定文件夹或项目的读取权限时，可以同时使用品牌手册、产品文档、历史稿件、案例、访谈和个人笔记。MediaClaw 提供平台证据与方法，你的知识库提供事实、观点和表达边界，当前 Agent 负责把两者组合成内容。

### 5. 输出形式不局限于一篇稿件

除图文和视频稿外，还可以要求 Agent 生成系列选题、内容日历、创作任务书、跨平台改写、Markdown/HTML 研究报告，或先比较多个方案再写。

## 一条推荐的 Agent 创作指令

```plaintext
我在做一款面向独立创作者的效率工具。请先检查 MediaClaw 里已有的账号研究、单篇拆解和选题，必要时补充最小范围的真实数据；再读取我授权的品牌资料和历史文章，找出平台需求与我们已有观点的交集。先给出证据结论和 3 个选题，我确认后再把其中 1 个写成小红书图文稿。不要编造案例和数据，标出仍需我补充的事实。
```

这类指令包含了身份、目标、可用资产、决策顺序和事实边界。你不需要指定工具名或采集命令。

## 能力、费用与人工确认

- Agent 基于已有数据完成分析、选题和写作，不消耗 MediaClaw 积分。
- 基础采集遵循插件当前的访问节奏和安全上限，Agent 不能绕过。
- 批量详情增强会在执行前说明范围并等待确认。
- 视频逐字稿会先返回逐条预计积分、总额和余额；只有你明确同意报价后才开始。
- 数据清理会先展示影响范围，必须再次人工确认；Agent 不会自行删除资产。

## 常见连接问题

### 已安装接入包，但没有检测到浏览器扩展

确认扩展安装在当前准备使用的 Chromium 浏览器中，并已启用；再到 **设置 → Agent 接管** 开启本机调用。不要重复安装 Agent 接入包。

### 已检测到设备，但还不能执行

回到扩展的 Agent 接管页面，核对设备并点击 **批准配对**。检测到设备不等于已经批准。

### 连接中断

保持原 Agent 任务，不要重复发起采集。在扩展中重新开启本机调用或点击重连，再让 Agent 检查原任务状态。

### 提示会员无效

回到扩展完成会员验证。不要把激活码发给 Agent。验证后重新开启 Agent 接管，已批准设备通常会自动恢复。
